# Other Side of the Wall

Meme-game entry for the KNOTS meme contest (28 Sep–5 Oct 2026).

This folder is a build handoff, not the game. Drop it in a GitHub repo and point Claude Code at `CLAUDE.md`.

## What this is

A 25-second browser toy. The player is the guy staring at a wall of green candles. Nothing happens until he flips the wall. Then $STONK becomes $KNOTS, he holds, and other people's transfers drop 3% crumbs into his lap as $STONK. If he touches himself, he sold, and the crumbs stop.

The joke is the inactivity. He wins by doing nothing.
